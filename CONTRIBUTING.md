# Contributing

Report bugs and suggestions in [Issues](https://github.com/GU12LHERME/CHDify/issues). Create a separate branch, run relevant tests, document results and preserve third-party licenses. Never upload credentials, personal data or copyrighted disc images.

---

# Contribuindo com o CHDify

Relate problemas e sugestões na [aba Issues](https://github.com/GU12LHERME/CHDify/issues).

## Desenvolvimento

1. Consulte a [documentação técnica](docs/DEVELOPMENT.md).
2. Crie uma branch para a alteração.
3. Execute os testes relevantes e descreva os resultados no pull request.
4. Preserve as licenças e a procedência das dependências do MAME.

Não inclua chaves de assinatura, credenciais, dados pessoais ou imagens de jogos protegidas. Utilize imagens sintéticas para reproduzir problemas sempre que possível.
